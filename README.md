# 💼 Yash Vardhan Singh - Portfolio

A modern, responsive developer portfolio built with **React**, **Vite**, and **Tailwind CSS**. It showcases my projects, technical skills, coding profiles, certifications, and contact information.

## 🌐 Live Demo

🔗 https://yash-portfolio-phi-ashy.vercel.app

---

## ✨ Features

- 🎨 Modern black & gold UI
- 📱 Fully responsive design
- 👨‍💻 About Me section
- 🛠️ Technical Skills
- 🚀 Featured Projects
- 💻 Coding Profiles
- 📜 Certificates with PDF preview
- 📄 Downloadable Resume
- 📬 Contact Section
- ⚡ Smooth scrolling navigation
- 🌙 Clean and minimal design

---

## 🛠️ Tech Stack

- React.js
- Vite
- Tailwind CSS
- Lucide React
- React Icons

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/portfolio.git
```

Navigate to the project:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
